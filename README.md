# Marks-Predictor-MLR
A Machine Learning project that predicts student performance using Multiple Linear Regression. It explores data analysis and visualization with Pandas, Matplotlib, and Seaborn, and includes a Streamlit interface with two prediction methods: a saved model and a manual calculation using regression coefficients.
